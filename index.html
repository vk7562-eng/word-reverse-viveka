Reverse a word

A stack gives back items in the opposite order they went in. Push each letter, then pop them all.

Input letters

Stack (top is highlighted)

Output

Press “Step” to push the first letter.

Stack operations used

Phase 1 pushes every letter in order (O(1) each). Phase 2 pops every letter until the stack is empty (O(1) each). The whole reversal takes O(n) time and O(n) extra space.
